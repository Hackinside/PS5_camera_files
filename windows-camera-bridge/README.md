## Optional Windows capture bridge

With the camera firmware loaded and Windows showing USB Camera-OV580, this bridge opens the stereo stream and publishes a processed 1920×1080 view to OBS Virtual Camera. Install uv and OBS Studio with its virtual camera component. Leave the OBS virtual camera output stopped so the bridge can use it.

Double-click PS5-Camera.cmd to preview the left eye. Select OBS Virtual Camera in the receiving app. From a terminal, pass right or stereo to change the preview, or test to check color in both eyes. The stereo preview publishes the left eye. The launcher uses uv to acquire its Python dependencies on first run.

Auto midtones measures the central subject twice a second and adjusts the tone curve toward Subject target. The adjustment slows near the target and stops brightening when central highlights approach clipping. Turn Auto midtones off for manual control. Auto gain is separate and defaults to off. Gain, saturation, denoise, shadows and highlights can be adjusted while streaming.

To set white balance, center an evenly lit neutral card and press W in the preview. Calibration is stored under the current user's local application data. Press Q to exit. Manual sliders reset on restart. If the preview is waiting, check the firmware loader and close any other app using the physical camera.
